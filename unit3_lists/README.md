## Overview

This assignment examines insertion, deletion, and searching in Python lists.

## Learning Objectives

- Insert values into a list
- Delete values from a list
- Search for values in a list
- Analyze list behavior and performance

## Implementation Summary
The Unit 3 program was implemented using Python lists to demonstrate insertion, deletion, and search operations. Values were inserted at the beginning, middle, and end of the list to show how existing elements shifted when new values were added. Items were also removed from different positions, and the removed value and updated lists were displayed. A linear search was implemented to return the index of an existing value or -1 when a value was not found. Edge cases were also tested by attempting to delete an invalid index and inserting a value into an empty list. Comments were added throughout the program to explain the implementation and how the different list operations worked.

## Real-World Scenario
I created a music playlist example to demonstrate how lists can be used in a real-world application. I added a song to the playlist, searched for a specific song, and removed a song. This demonstrated how list operations could be used to manage songs in the playlist.
